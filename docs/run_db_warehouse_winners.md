# الأصناف الفائزة حسب المخزن

اختر التشغيل من صفحة Run Results (Database). يظهر قسم الأصناف الفائزة أعلى
الجداول القديمة، ويعرض جدولًا لكل مخزن أو ملف Excel لديه صنف فائز. زر
«تحميل جميع المخازن» ينزّل ZIP يحتوي ملف Excel مستقلًا لكل جدول، ولا يتأثر
بفلاتر الجداول القديمة.

المقارنة تستخدم سعر الشراء المحفوظ دون إعادة تطبيق الخصم، وتستبعد الكميات
صفر والأسعار غير الصحيحة أو غير الموجبة. عند تعادل السعر يُفضّل Excel، ثم
مخازن توريد بالترتيب: البركة، الماسة، الشفاء ميدكو، ألفا فارما، مصر مديكال،
نيو سيدرا، الريان. التعادل المتبقي يُحسم بالاسم ثم هوية المخزن والصنف.
قد تقل الكمية المتاحة عن المطلوبة؛ هذا التقرير لا يوزع الطلب ولا يعدّل السلة.

العملة الفارغة تُعامل كجنيه مصري (EGP)، وهو الافتراض الافتراضي للتشغيل المصري
الحالي؛ لا توجد عملة تشغيل قابلة للضبط في إعدادات المشروع. يُستثنى الصنف
إذا احتوت عروضه المؤهلة على عملات مختلفة، مع توضيح ذلك في الصفحة.

يحفظ إصدار قاعدة البيانات 6 نتائج المقارنة وأسباب الاستبعاد في
`run_warehouse_winners` داخل معاملة حفظ الصنف. تُحدّث النتيجة عند وصول عروض
مصدر آخر، وتبقى مستقلة عن علامات الفائز في الطلب الحالي. ترقية القاعدة تعيد
بناء النتائج القديمة من العروض الباقية فقط؛ لا تسترجع عروضًا حُذفت أو لم تُحفظ.
كمية Excel هي الكمية التي سجّلها مسار الاستيراد، وقد تكون علامة توافر بقيمة 1
في ملفات الأسعار التي لا تحتوي على رصيد فعلي.
