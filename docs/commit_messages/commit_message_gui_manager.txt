feat(ui): add/remove Excel target catalogs from the GUI

Operators no longer have to edit state/config.yaml by hand to add a
new Excel target. The Run Order tab now exposes:

* A "+ Add Excel target" button under "What to run against?". The
  button opens a dialog with a default name
  ("المخازن الادويه المباشرة"), a file uploader for the catalog, and
  editable text inputs for the product/price/discount column names.
  The bytes are written to artifacts/uploaded-excel-targets/<key>.xlsx
  and a new entry is appended to the user_added_targets section in
  state/config.yaml.
* A "🗑 Remove <key>" button per user-added target. Hard-coded
  targets (those that already lived in state/config.yaml) are
  protected — only operator-added entries are removable.

The user_added_targets section is the new source of truth for
"this catalog was added from the UI, so it is safe to remove from
the UI". Removing an entry drops the key from excel_targets and
from user_added_targets. The persisted catalog file is left in
place under artifacts/ so the operator can keep a backup.

render_order_tab now reloads the AppConfig whenever an add/remove
toast fires, so the checkbox group, the multiselect, and the trash
buttons all reflect the new state on the very next rerun.

Files:
